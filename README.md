# 🔐 MERN Authentication System

A full-stack authentication system built using the MERN stack. This project implements secure user authentication, email OTP verification, password reset functionality, protected routes, and session management using JWT and cookies.

## ✨ Features

- 📝 User Registration
- 🔑 User Login
- 🔐 JWT-based Authentication
- 🍪 Authentication using HTTP Cookies
- 📧 Email OTP Verification
- 🔄 Resend Verification OTP
- 🔒 Protected Routes
- 🚪 Secure Logout
- 🔑 Forgot Password
- 🔄 Reset Password
- 🔒 Password Hashing using bcrypt
- 👤 User Account Verification
- ⚡ RESTful API
- 📱 Responsive User Interface
